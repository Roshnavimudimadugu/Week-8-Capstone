# RNA-seq Differential Expression Capstone

## Objective

Perform RNA-seq differential expression analysis, starting from a gene count matrix and sample metadata through statistical analysis and biological interpretation.

## Workflow

1. Dataset description
2. Sample metadata review
3. Quality-control assumptions
4. Differential expression analysis using DESeq2
5. Principal component analysis (PCA)
6. Heatmap and volcano plot
7. Top differentially expressed genes
8. Functional enrichment analysis
9. Biological interpretation
10. Limitations and assumptions
11. Reproducibility instructions

## Expected Outputs

- Differential expression results table
- PCA plot
- Heatmap
- Volcano plot
- Top differentially expressed genes table
- Functional enrichment results
- Biological interpretation
- Limitations and reproducibility documentation
