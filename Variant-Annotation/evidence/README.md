# Variant Annotation Evidence

This folder contains screenshots documenting the variant annotation workflow and supporting evidence.

The evidence includes:

- **Galaxy workflow:** Screenshots of the computational workflow and analysis history.
- **SnpEff annotation:** Candidate variant annotation, predicted consequence and impact.
- **gnomAD:** Population allele frequency and homozygous alternate count.
- **dbSNP:** Variant identifier, genomic information and submission details.
- **ClinVar:** Search evidence documenting the clinical database review.

These screenshots provide supporting evidence for the candidate variant analysis and its preliminary interpretation.
