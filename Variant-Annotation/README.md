# Variant Annotation Capstone

## Objective

Develop a variant annotation workflow starting from a VCF file and progressing to evidence-based interpretation.

## Workflow

1. Identify the variant data source
2. Review and filter variants
3. Annotate genes and transcripts
4. Identify variant consequences
5. Review ClinVar evidence
6. Review gnomAD population frequencies
7. Examine disease-associated evidence
8. Identify conflicting evidence
9. Document limitations
10. Prepare the final variant annotation table
11. Provide reproducibility instructions

## Expected Outputs

- Filtered variant table
- Gene and transcript annotations
- Variant consequence annotations
- ClinVar and gnomAD evidence
- Disease evidence and conflicting interpretations
- Final annotation table
- Limitations and reproducibility documentation
